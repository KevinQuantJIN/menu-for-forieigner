## 0. 一句话目标

把 `ui-prototype` 分支的**最新视觉与交互**（模块化 css/js + 柿漆金排档 v-final + stage.html 舞台壳）合入 `v0` 分支，同时**保留 v0 的全部功能逻辑**（契约 v1 对齐、真实相册上传、`/api/analyze` NDJSON 流式接入、错误处理、Lab 评测），最终得到"最新 UI + 真后端"的可运行版本。

## 2. 红线（任何任务都不得违反）

1. **禁改视觉**：`public/css/*.css`、`public/stage*.html`、`public/logo.svg` 的样式值（颜色/字体/间距/圆角/阴影/动画）一律不动。允许的唯一例外：T7 里**新增**少量类（错误行/重试钮/缩略条），且只能复用 tokens.css 里已有的变量与 `.btn .btn-ghost` 等既有类。
2. **禁改后端**：`src/**`、`next.config.ts`、`wrangler.jsonc`、`package.json` 一律不动。合并后 `npm test` 必须依旧全绿（基线 27+ tests）。
3. **禁破坏 stage.html 依赖契约**（§3 全局契约表）。stage.html 本身不改，是**app 侧必须继续提供**这些符号。
4. **UI 上的产品决策以 ui-prototype 为准**，v0 里与之冲突的旧交互**不移植**，包括：
   - ❌ 折叠逻辑（`foldBar`/`foldedCards`/`toggleFold`）——7.13 Julia 已定：命中过敏的菜**不折叠**，只保留行内红 ⚠ tag；
   - ❌ 首页 profile 横条（`renderProfileStrip` 的 DOM）——7.12 已移除，函数保留但遇 null 直接 return（ui 的 home.js 已是如此）；
   - ❌ 点单页 guide-banner 与 `NOTE` 提示块——order-card-final 定稿已用新结构覆盖；
   - ❌ 价格列里的 "not spicy" 文案——7.13 定稿辣度 🌶 icon 缀菜名旁；
   - ❌ 菜名前 emoji、详情价格行、菜系行——v-final 均已删除。
5. **数据/文案红线**（继承 HANDOFF）：过敏原不滥标；story 宁 null 不编；¥ 原价永远保留；免责声明不删；数字等宽。
6. 每个任务完成后**单独 commit**，commit message 用本文的任务编号开头（如 `T3: port normalizeDish & personalization into core.js`）。

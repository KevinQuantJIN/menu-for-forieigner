> 2026-07-12 · 配合 PRD.md 使用。demo 用菜单分两层：
> **A. Mock 菜单**（预生成图片，可控内容，保证每道菜都打一个演示点）——用于现场 demo 主线和 app 内预置示例
> **B. 真实菜单**（实拍照片）——用于视频里「真实拍照 → 流式出结果」的可信度镜头

## D. 还需要更多真实菜单时去哪找

1. **实拍最优**：去楼下任意川菜馆/面馆拍一张（视频里至少要有一段真实餐厅环境的实拍镜头，可信度无可替代）；手写水牌/苍蝇馆子菜单是加分项——展示 VLM 读手写的能力
2. **打印 mock 菜单再拍**：把 A 的图打印出来放在餐桌场景里用手机拍——「拍照流程」真实、内容可控，适合棚拍
3. 大众点评/小红书商家页的公开菜单相册（遵守 repo 红线：单店少量、不登录、不批量）
4. Google Images / 小红书搜「菜单 实拍」「苍蝇馆子 菜单」

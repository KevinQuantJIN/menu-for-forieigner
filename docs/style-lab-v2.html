反 AI 质感实验室 · 三方案

共同纪律（取自顶级实践与 taste/impeccable 方法论）：禁纯黑（一律苍墨 #262019 级 off-black）、禁高饱和荧光、禁「白底+圆角+浅阴影」万能卡——每一版的容器与线条都有明确工艺出处； 数字一律等宽字体；阴影必须带环境色相；全局矿物/纸张颗粒。主色全部避开土黄陶土系（Claude 色带）。

方案一

雕版食单

Woodblock Ledger · 墨 × 朱印

整个 app 是一册木刻印刷的食单：全平面、零阴影、零卡片——层级全靠线条工艺：外粗内细的「文武边」大框、发丝分隔线、菜名与价格之间的引导点线（leader dots）、【鱼尾】节标。 朱红只做印章与警示，永不铺面。点亮省份 = 在地图上钤一方朱印（微旋转，人手盖章的不齐）。这是三版中「印刷手工感」最强、离 AI 最远的一版。

线条：文武边双线框 · 发丝线 · 点线引导字体：宋体大标 + 等宽数字质感：纸纹 + 零阴影全平面点睛：朱印章（微旋转）

方案二

夜窟青金

Azurite Night · 石青 × 鎏金

敦煌的另一半：不取沙壁的暖，取夜窟的石青深蓝 × 壁画鎏金。首屏与地图沉在深青夜色里（星点、金月、藤黄点亮省），内容层像一张米白手账从夜色里升起（圆角浮层）。 卡片不用灰阴影——用描金发丝框（inset 金线）+ 蓝调环境阴影。气质最「高级馆藏」，且蓝金与 Claude 橙完全无关。

线条：描金发丝框（inset 1px 金）字体：宋体标题 + 等宽数字质感：夜色渐层 + 星点 + 蓝调阴影点睛：金月 / 藤黄点亮

方案三

大排档招牌

Canteen Sign-Painting · 食堂绿 × 辣椒红 × 蛋黄

中国街头食物的视觉母语：老食堂绿墙裙、手写价目牌、搪瓷缸、印刷套色错位。线条语言是 2px 苍墨实线描边 + 无模糊的偏移硬阴影（就是老海报套色没对准的那 3px）， 价格做成蛋黄底手写价签斜贴在卡片上，徽章微旋转像贴纸。楷体标题自带人手味。三版中最活泼、最「跳脱」、小红书传播脸最好——而且 neo-print 风格和 AI 默认审美是两个宇宙。

线条：2px 墨线描边 + 3px 套色错位硬阴影字体：楷体标题 + 等宽数字质感：纸纹 + 贴纸微旋转点睛：蛋黄价签 / 图钉地图

三版的本质区别（不是配色，是工艺）：A 是「印刷品」（零阴影、线条分层、盖章交互）；B 是「馆藏夜场」（深色场景+鎏金细节+浮层）；C 是「街头招牌」（描边+套色错位+贴纸）。 我的判断：A 最高级最独特、评委过目不忘，但活泼度靠朱印与文案撑；C 最符合「美食跳脱五彩」且执行容错高；B 居中但首屏深色在餐厅强光下可读性要实测。 可混合：A 的菜单 list 线条工艺 + C 的地图与价签 + 任一色系都成立。定稿后 tokens 进 UI-DESIGN.md 再动 app.html。
